Building the demo

The demo found three bugs.

A tone that began inside a window had no pitch

it failed one run in three on Android 17, and passed on 15 by luck of timing.

A capture saved into a folder not yet made was lost

after it had stopped. The repository's own test file found it.

A tap's click read as 12 Hz

found walking the tutorial. A pitch now has to repeat three times.

Each was fixed with a test that failed first, and each is written up in Mobium's challenges log. Writing the quick start and tutorial from scratch is what found the last two.
